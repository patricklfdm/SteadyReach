# 安装入口

[English](GETTING_STARTED_EN.md) | [简体中文](GETTING_STARTED_CN.md)

首页点击 **新建项目**，或在 **已保存的项目** 中展开某个地点继续。新地点选坐标；已有 `survey.json` 和清单附件时选实测河道资料包；已有受支持的涵洞模型时选原生 HEC-RAS 工程。参数页分别显示 HEC-RAS、报告和 GIS 的开算前预检。选择地图交付时，程序检查拟出图范围的地形覆盖。若 GIS 提示需处理，可以修正地形，或主动改为仅交付水力结果和报告，再次确认。已有原生模型的最终地图范围可能要在几何编译后核对。必要资料齐全后，点 **核对运算输入**。如需修改草稿，按现场资料、地图与断面、水力参数找到对应内容。核对估计项和交付范围后，再确认运行。

运行后先看 **结果总览**，这里显示流量、水位和首要复核事项。原生警告和敏感性试算在 **水力复核**。中英文 PDF、QGIS 和两种交付包在 **报告与地图**。回到首页后，展开一个地点即可找到原版及其修订，版本管理操作位于各版本内部。

**草稿与采用。** 首页的文字和选项暂存在当前浏览器标签页。切换语言、返回项目列表或刷新后，可以继续选择待采用的参数和岸站。点击 **保存全部所选更改** 或 **核对运算输入** 才会把这些选择写入模型；直接编辑的参数仍自动保存。页面刷新后若提示重新选择附件，按列出的文件名选择。现场反馈按洪水事件分别暂存，点击 **保存并预览现场反馈** 后写入项目。

**选择修订与恢复批次。** 首页按修订序号、用途、本机时间和最近任务区分版本。已有水力结果且后续批次中断时，结果页分别列出当前交付状态、已算工况与重试范围。点击继续前核对该范围；需要补算的工况会调用 HEC-RAS。

**从一个坐标开始。** 首页选 **纯河道（不建桥梁）**，填项目名和定位点，未知数值留空。程序查询 USGS 有流向的河网和附近道路交叉处，并按候选弯道和断面范围准备 DEM。进入 **自动提出 DEM 布置／QA 修正**。若定位点靠近交叉口，按两个道路名称选择目标河段。生成预览，对照航片核对河线与岸站后采用。参数页集中列出已填值、来源、假设和缺项，最终确认后启动 HEC-RAS。[纯河道操作详解](RIVER_REACH_CN.md)

不含结构物的河段请选择纯河道，并按[纯河道指南](RIVER_REACH_CN.md)操作：省去涵洞/道路字段，明确河床表示方式和实际边界。下文涉及交叉口的步骤适用于涵洞项目。

新地点导入现有材料并核对过路位置及高程信息后，点击 **自动准备草稿（含标注的估计值）**。复核突出显示的不确定项和完整参数清单，再点 **确认并运行 HEC-RAS**。

没有已有模型时，使用[集中自动化准备](AUTOMATION_CN.md)，减少重复转录参数和逐条确认岸站。

参阅 [Windows 安装指南](WINDOWS_SETUP_CN.md)，再按[用户手册](USER_GUIDE_CN.md)操作。日常入口为 `start_workflow.cmd`。

运行后可阅读[结果复核、修订与敏感性](RESULTS_REVIEW_CN.md)，了解可选原生输出补齐、一键打开 QGIS 副本及保留旧结果的重算。

草稿有缺项时，从 **现在先做什么？** 开始。页面可带你前往断面修正、自动准备或来源核对。需要外部资料时，点击 **导出待索取资料（CSV）**，按表中单位填写，在现场资料中导回并选择候选。获得结果后，在 **报告与地图** 点击 **校验双包并生成收件人说明**，即可获得本次运行的双语阅读入口。
