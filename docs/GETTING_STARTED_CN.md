# 安装入口

[English](GETTING_STARTED_EN.md) | [简体中文](GETTING_STARTED_CN.md)

没有已有模型时，使用[集中自动化准备](AUTOMATION_CN.md)，减少重复转录参数和逐条确认岸站。

参阅 [Windows 安装指南](WINDOWS_SETUP_CN.md)，再按[用户手册](USER_GUIDE_CN.md)操作。日常入口为 `start_workflow.cmd`。

运行后可阅读[结果复核、修订与敏感性](RESULTS_REVIEW_CN.md)，了解可选原生输出补齐、一键打开 QGIS 副本及保留旧结果的重算。
