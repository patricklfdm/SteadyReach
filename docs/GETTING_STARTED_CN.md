# SteadyReach 首次使用指南

[English](GETTING_STARTED_EN.md) | [简体中文](GETTING_STARTED_CN.md)

在 Windows 上，把仓库解压到可写的本机文件夹，双击 **start_workflow.cmd**，保持控制台窗口打开。浏览器会显示项目首页。[安装和软件要求](WINDOWS_SETUP_CN.md) · [用户手册](USER_GUIDE_CN.md)

1. 只有定位、照片、PDF 或零散测量表时，选 **坐标／部分资料**，建项后由程序查找公开资料，也可以导入手头的文件。已有 `survey.json` 和配套文件时选 **已整理的实测河道资料包**；已有受支持的涵洞恒定流原生文件时选 **已有 HEC-RAS 工程**。
2. 在 **准备模型** 页先处理排在前面的建议操作。在地图上核对河段或涵洞位置、断面和候选岸站，再核对估计值，按缺项补测或补资料。
3. 点 **核对运算输入**。若有阻塞项，点 **查看待处理检查** 定位，修正后保存并刷新清单。通过后点 **前往最终确认**，核对假设并勾选，再运行 HEC-RAS。
4. 到 **结果总览** 查看适用用途和主要限制。需要查证据或建立修订版时进 **水力复核**；需要 PDF 和交付包时进 **报告与地图**。

第一次使用时，可以在空白首页展开 **试做一个河道算例**。选择一个 Manning 糙率，查看 East Fork 同一场洪水在 RS 516 的水位变化，再点 **打开练习报告** 比较全部四条断面。练习读取已核验的 HEC-RAS 工况，选择暂存在当前标签页。进入正式项目后，先按工程目标选择地点类型。取两桥之间的河段且两端不建桥，选 **两桥之间的河道**。要计算涵孔、涵前水位或路面溢流，选 **水流通过一孔或多孔涵洞**。

## 场地资料、复核与修订

开始选边界或索取补件前，打开 **水力资料清单与离线重放 → 查看水力资料**，检查资料缺项、测站适用性和来源版本。补件后可集中确认变化项。[资料清单与补件操作](HYDRAULIC_INTAKE_CN.md)

**先约定这次计算交付给谁、用来做什么。** 打开“用途和过流路径 → 本用途的交付条件”，选场地初筛、方案比较或工程复核，再选择采用条件。可指定计算工况、断面端点不过水、有原件支持的场地几何。涵洞可设最小道路余高。河道可指定独立实测事件、观测断面 RS 和最大绝对水位误差（ft）。数值限值由项目约定并填写依据。开算确认页会列出随本版冻结的条件。

首页点击 **新建项目**，或在 **已保存的项目** 中展开某个地点继续。新地点选坐标；已有 `survey.json` 和清单附件时选实测河道资料包；已有受支持的涵洞模型时选原生 HEC-RAS 工程。参数页分别显示 HEC-RAS、报告和 GIS 的开算前预检。选择地图交付时，程序检查拟出图范围的地形覆盖。若 GIS 提示需处理，可以修正地形，或主动改为仅交付水力结果和报告，再次确认。已有原生模型的最终地图范围可能要在几何编译后核对。必要资料齐全后，点 **核对运算输入**。如需修改草稿，按现场资料、地图与断面、水力参数找到对应内容。核对估计项和交付范围后，再确认运行。

计算后查看“结果交付评估”和中英文完整报告首页。超限时按列出的断面或参数修订，缺证据时按提示补实测资料。若修改模型输入或约定条件，建立可编辑修订版、重算、选定工作版本，再导出收件人说明。仍有开放问题时可交接诊断材料。正式使用范围还要结合水力 QA 限制，由负责工程师决定签发。

查询磁盘占用、固定版本或恢复工作文件时，从 **已保存的项目 → 管理此版本 → 版本存储与恢复** 进入。归档期间已发布的交付包仍可打开。[按版本归档、释放空间和恢复](LOCAL_RELEASE_CN.md#按版本归档释放空间和恢复)

**草稿与采用。** 首页的文字和选项暂存在当前浏览器标签页。切换语言、返回项目列表或刷新后，可以继续选择待采用的参数和岸站。点击 **保存全部所选更改** 或 **核对运算输入** 才会把这些选择写入模型；直接编辑的参数仍自动保存。页面刷新后若提示重新选择附件，按列出的文件名选择。现场反馈按洪水事件分别暂存，点击 **保存并预览现场反馈** 后写入项目。 同一标签页切换语言会保留所选的实测目录。刷新浏览器后，需重新选择目录。

**选择修订与恢复批次。** 首页按修订序号、用途、本机时间和最近任务区分版本。已有水力结果且后续批次中断时，结果页分别列出当前交付状态、已算工况与重试范围。点击继续前核对该范围；需要补算的工况会调用 HEC-RAS。

**从一个坐标开始。** 首页选 **纯河道（不建桥梁）**，填项目名和定位点，未知数值留空。程序查询 USGS 有流向的河网和附近道路交叉处，并按候选弯道和断面范围准备 DEM。进入 **自动提出 DEM 布置／QA 修正**。若定位点靠近交叉口，按两个道路名称选择目标河段。生成预览，对照航片核对河线与岸站后采用。参数页集中列出已填值、来源、假设和缺项，最终确认后启动 HEC-RAS。[纯河道操作详解](RIVER_REACH_CN.md)

不含结构物的河段请选择纯河道，并按[纯河道指南](RIVER_REACH_CN.md)操作：省去涵洞/道路字段，明确河床表示方式和实际边界。下文涉及交叉口的步骤适用于涵洞项目。

新地点导入现有材料并核对过路位置及高程信息后，点击 **自动准备草稿（含标注的估计值）**。复核突出显示的不确定项和完整参数清单，再点 **确认并运行 HEC-RAS**。

没有已有模型时，使用[集中自动化准备](AUTOMATION_CN.md)，减少重复转录参数和逐条确认岸站。

运行后可阅读[结果复核、修订与敏感性](RESULTS_REVIEW_CN.md)，了解可选原生输出补齐、一键打开 QGIS 副本及保留旧结果的重算。

草稿有缺项时，从 **现在先做什么？** 开始。页面可带你前往断面修正、自动准备或来源核对。需要外部资料时，点击 **导出待索取资料（CSV）**，按表中单位填写，在现场资料中导回并选择候选。获得结果后，在 **报告与地图** 点击 **校验双包并生成收件人说明**，即可获得本次运行的双语阅读入口。

## 从涵洞照片和定位点开始第一次计算

在模型准备页打开 **从涵洞位置开始**，导入现场照片、地点文件和水文报告。对照原件查看已有数据、条件性数值及待补参数，点参数名称即可编辑。按组在 DEM 上标出进口和出口，或关联已测洞口。点击 **预览河段锚点与断面**，先用照片核对流向，再检查断面覆盖、相交和岸站剖面。采用当前几何后，程序会推导关联参数。在开算确认页集中核对流量、糙率、尺寸及估算涵底，再确认运行。

收到道路图纸或说明后，在结果页进入 **修改参数／对比重算 → 创建可编辑修订版**。导入补件，选中相应来源的路宽，点击 **比较路宽和道路剖面**。查看原文、原路宽与建议宽度、道路相对上游断面的距离及上下游堰顶剖面。六个关联参数都有唯一推导时，可与路宽一次采用。有独立测量值或多种解释时按提示逐项复核。资料给出的名义路宽能否用作有效越流宽度，仍需工程判断。核对修订版参数后再运行，比较两次结果再选定交接版本。

## 从未满足条件走到选版交接

- **断面端点过水**。在结果总览选提示中的 RS，点 **查看计算断面**。对照本版航片、计算水位、相邻断面和过水端点，判断外侧是否确有连通漫滩。需要改几何时点 **在修订版调整此湿端断面**，在独立草稿调整方向或宽度，预览 DEM，核对岸站和关联输入，再确认重算。回到两版对比核查湿端和水位变化。
- **涵底仍是估计**。点 **索取各组进出口涵底高程**，下载表格。每行对应一个孔组的一端，先前估计与待填值分列。把表交给资料提供方，保留孔组、端别、单位、高程基准及版本标识，填写数值、来源并区分原件记载与假设。可暂停等资料，收到后从同一版创建独立修订并导回。检查匹配结果，有歧义的行逐项核对，再确认计算。
- **路面越流量显示未知**。从结果总览打开本次原生输出，在 HEC-RAS 核对相同运行、方案、工况，再导出路面越流量。缺记录时应保留“未知”。
- **选版交接**。比较补件、关键数值、遗留条件后，可保留基准版、选修订版或暂停。点 **按所选用途准备交接**，整体转交生成的文件夹。收件人双击根目录中文或英文入口即可检查用途和报告。

### 判断修订是否有效，确认收件人拿到正确版本

在 **选择使用版本或暂停复核** 下展开 **查看各断面端点**，按状态筛选，再选 RS 打开本版地图和剖面。端点水深为正，表示计算水位高于该版端点地面。延伸后端点会落在不同地面上，某一侧若持续过水，需结合航片判断漫滩是否连通。纯河道对照上下游水位、主槽最大流速和弗劳德数；涵洞对照涵前水位、涵后水位和路面越流量。

完整复制 `Handoff_…` 后，用 Edge 或 Chrome 打开目录中的 `Start_zh-CN.html`。在 **校验复制后的交接目录** 选择该目录，等到显示文件总数和运行编号。若提示异常，按相对路径从选定版本重新复制，再校验一次。需要在 HEC-RAS 里编辑时另建工作副本。收件人可以离线完成校验，无需安装 SteadyReach。
