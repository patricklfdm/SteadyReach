# 候选版本安装与故障响应

[English](CANDIDATE_EN.md) · [安装、核验与回退命令](OPERATIONS_CN.md) · [试点记录表](FIRST_PILOT_CN.md)

**部署目标。** Windows x64 本地运行，Python 3.12.14、已核验的 HEC-RAS 7.0.1 美制单位适配器、QGIS 3.44 LTR 及配置的 LibreOffice。原生警告与分组表导出依赖支持的英文桌面会话及剪贴板。候选安装与现用版本并存，工作站配置与签名私钥另行保管。

**交给 IT 的材料。** 签名发行目录包含 RELEASE.json、RELEASE.sig、源码与依赖归档、软件物料及许可证清单。通过独立渠道向发行管理员获取公钥指纹。先验证签名和文件再安装，绑定本机工具后检查两类用途模板并核验一份已有的客户包。工单填写清单中的提交号。

| 故障现象 | 首先做什么 | 恢复核验 |
| --- | --- | --- |
| 外网中断或数据源不可用 | 优先使用冻结输入，保留真实缺口，取得资料后继续。 | 核对原件指纹、事件、单位和高程基准。 |
| 工作盘不足 | 查看容量估计，保留已确认版本与登记成果，换归档卷或回收暂存。 | 新任务开始前空间预检通过。 |
| 桌面锁定或不可用，无法导出原生表 | 在支持的已登录桌面恢复导出。 | 原生运行与 HDF 一致，缺表在验证前保持未知。 |
| QGIS 或 PDF 导出超时 | 打开已有计算重试交付。 | 两包清单、运行编号和应有报告校验一致。 |
| 升级出现回归 | 单独保留升级后新工作，再使用已登记迁移凭据回退。 | 旧安装能重新打开其项目，成果指纹一致。 |

**支持分工。** 试点单位在推广前指定工作站管理员、水力负责人和发行维护人。管理员负责安装恢复，水力负责人批准项目用途，维护人跟踪可复现的软件故障。先预览本机诊断 JSON，客户原件通过批准的私有渠道传递。工单记录版本、严重度、已尝试操作、负责人及恢复结果。正式推广前协商响应时段、补丁时限及终止支持日期。依赖出现安全通告后核对固定物料清单，判定影响，签发替代版本并演练回退。客户机验收、独立工程签审与合同响应时限另行确认。
