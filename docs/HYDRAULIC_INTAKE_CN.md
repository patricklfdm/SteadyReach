# 从原始资料到确认水力输入

[English](HYDRAULIC_INTAKE_EN.md)

## 直接从测量原表填报

1. 打开已准备的项目，展开 **导入原始测量表 → 从我的测量表开始**。河道测点需要已定位的断面。选择 2 MB 以内、最多一万行的 UTF-8 CSV 或制表符表。USGS 现场测验也可直接选 field-measurements 的 GeoJSON。Excel 工作簿请先将所用工作表另存为 UTF-8 CSV。
2. 点击 **读取表头并建议匹配**。例如 `X,Y,measwse` 会匹配平面位置和水面高程。随项目登记的 FGDC XML 明确提到此文件和属性时，页面会列出相应单位与基准。核对事件日期、流量、工况及测量坐标系；文件名推测的日期和模型流量都需要对照原件。来源列非空时优先于整表填写值。
3. 点击 **定位并预览原始行**。纵向水面测线上，每条已定位断面查找距中心 5 m 内、也能唯一匹配该断面的最近测点。表格显示原始行号、候选用途及同一断面附近的其他行。超距、重复、同距歧义和基准冲突会提示处理。偏离中心的洪痕或受桥墩影响的水迹还需另外定位。可回到列名或原件修正后再次预览。
4. 单工况缓流或混合流的草稿可采用一个原位出口。若测量未给出垂直精度，初筛／复核用途需要额外勾选条件性采用。运算前页面隐藏其余内点的水位。已计算版可以提交同一事件中未参与调参或设边界的内点，确认后会建立独立修订版。两次操作均沿用原有的最终参数确认。
5. 异地水尺按站号与测次配对读数和流量，可在面板核对其位置、距离及基准。取得水尺零点、事件和传递依据后，再按下文的测站边界步骤处理。涵洞项目支持 `group,inletinvertft,outletinvertft,datum`，亦可用 `group,end,elevation,unit,datum`。组号从 1 开始；端别可填 `inlet` 或 `outlet`。未测端留空即可单端回传，系统会保留原值及其来源等级。


打开由坐标或实测包建立的项目，展开 **水力资料清单与离线重放**，点击 **查看水力资料**。建议在选边界或联系测量方前先看一次。草稿显示当前输入；计算版读取该版封存的输入。

| 类别 | 核对内容 | 最有用的补件 |
|---|---|---|
| 地形 | 工作 DEM、水平范围、高程基准、单位、产品版次 | 覆盖过水河段和两侧漫滩的栅格与高程控制资料 |
| 水下河槽 | 有实测依据的断面及河床高程来源 | 有测量日期、与项目同基准的水下断面 |
| 流量 | 工况、事件或年超越概率、流量、单位及来源 | 明确适用河段的频率表，或本次模拟事件的实测流量 |
| 水位 | 测站、日期、基准、单位、对应断面和不确定度 | 边界在同一事件的水位，或有依据的异地水位传递 |
| 涵洞等构筑物 | 孔组、进出口涵底、涵长和路面几何 | 记录组别、端别、基准和单位的测量表或竣工图 |

展开一类即可查看已用数值、估计和候选、来源文件及 SHA-256 指纹。产品发布日期和现场测量日期分别看待。原件没注明的信息可以留空。可编辑版本支持 **从原件补录资料信息**。选原件和类别，填写能查到的日期、范围、单位、基准或版次。同一原件、同一类别再次保存会替换该条元数据。基准不一致时，先查明转换关系再采用高程。

查询无匹配说明服务已响应；服务不可用时可以重试。部分返回和多源冲突分别显示。带假设的数值是否可用于初筛，取决于该项目已约定的用途。用于设计还需独立的工程依据。

## 判断测站水位能否用作下游边界

在采用已知下游水位的纯河道项目中，核对测站、工况、事件日期、流量、位置及高程基准。观测需注明单位和正的垂直不确定度。只有相对水尺读数时，另需与日期对应的水尺零点高程。查看实际测站坐标对应的断面。异地测站须有同一事件至下游边界的有符号高差、传递不确定度及原始依据。校准、独立复核或背景读数保留各自用途。传递资料暂缺时，可保留另有依据的边界，例如正常水深，并检验相应边界敏感性。

**Soquel 实例。** USGS 11160000 对应 RS 1700，距下游断面中心约 714 米。站点注明 NGVD29，模型采用 NAVD88。测站频率表可供选流量参考；要确定 Q100 尾水，仍需匹配的事件水位、基准和传递依据。**Dexter 实例。** 1,540 cfs 事件有实测流量和 RS 500 的独立水位；后者应留作算后对照。

### 可选的结构化记录

在实测资料包中提供 `observed_profiles.csv`，或用现有的现场回传入口。沿用观测表的事件、日期、用途、类型、坐标、水平 CRS、高程、单位、垂直基准、流量、不确定度及来源列。用 `profile` 标明模型工况，`source` 含如 `USGS-11160000` 的站号。作为边界候选时填 `role=boundary`，作为独立观测填 `holdout`。若为 `stage`，填绝对水位；若为 `gage_height`，填读数及同单位的 `gage_zero`。本项边界筛查适用于实际起控制作用的一维恒定流河道下游端。

实测资料包可另含 `intake_evidence.json`，用来关联事件、水尺零点和水位传递依据。把所引用的原始文件和声明文件一并登记在实测清单中。声明须引用实际原件的指纹。文件顶层 `schema` 值为 `intake_evidence_1`，各数组字段如下。

| 数组 | 每条记录的字段 |
|---|---|
| `records` | `category`（terrain、channel、flow、stage 或 structure）、`source_sha256`，以及原件载明的 `date`、`footprint`、`datum`、`unit`、`version` |
| `events` | `station`、`profile`、`event`、`date`、`source_sha256` |
| `gage_zeros` | `station`、`date`、`datum`、`zero_ft`、`source_sha256` |
| `datum_ties` | `station`、`event`、`date`、`from_datum`、`to_datum`、`source_stage_ft`、`offset_ft`、`uncertainty_ft`、`basis`、`source_sha256`。使用从测站基准转换的绝对水位时，原高程加有符号高差须与换算成英尺的观测值一致。 |
| `transfers` | `station`、`profile`、`event`、`date`、`target_rs`、`datum`、`offset_ft`、`uncertainty_ft`、`basis`、`source_sha256` |

日期用 YYYY-MM-DD，传递高差和不确定度用英尺数值。站号须能匹配已登记的 USGS 测站位置原件。传递后水位等于换算为英尺的绝对水位加有符号高差。用于已知水位边界的记录如有冲突或依据不足，开算前会提示处理。正常水深边界按其自身依据核对。

## 采用出口现场直接测得的水位

当绝对水位测点位于出口断面上时，将该点整理为一行 CSV，表头为 `x,y,elevation`，并在测量资料清单登记文件。在 `intake_evidence.json` 的事件中填写 `method: "direct_outlet_survey"`，用 SHA-256 绑定该点位原件。填写工况、事件、日期、平面坐标系、垂直基准、单位，并在 `point_source` 写明原件和行号。在 `observed_profiles.csv` 的边界行选择 `boundary_stage`，填写同一来源说明。Washington State Park 示例演示了如何从带日期的公开原件准备这些文件。

程序比对两份记录，检查测点是否唯一匹配下游断面，以及当日流量和采用的水位是否吻合。若资料未量化垂直测量精度，填写 `accept_unquantified_for_screening: true` 后可在初筛或工程复核用途中确认并进行条件性试算。确认页和报告会提示待补的精度依据。其他用途及不匹配的记录会被拦截。相对水尺读数和异地测站沿用前述零点及沿河传递检查。已用作计算条件的出口不参与独立残差评分。

## 冻结、重放和补件

1. 点 **冻结本次资料**，保存归档路径和 SHA-256 回执。归档含工作 DEM、本版登记的资料、已保存的查询原始响应及可取得的本地航片。未裁剪的大幅原始地形瓦片另列引用。
2. 点 **离线重放最近冻结资料**。程序逐一校验文件，从冻结原件重新生成清单，再比对指纹。即使原项目已离线，也可在已安装的仓库运行 `python -m ras_workflow.intake_freeze "<归档.zip>" --sha256 "<回执 SHA-256>"`。
3. 实测包项目可点 **恢复冻结的原始实测包**。目录内含原始清单及列出的文件；已归档的本地航片与回执在旁边的目录中。可从首页重新导入并计算。需要取回后续编辑的几何、计算结果和交接包时，用 **按版本管理存储与恢复** 恢复完整工作版。
4. 收到补件后，从已计算的父版本导入回传表或观测，核对单位和基准，再打开修订版的 **核对计算输入**。变化区会列出受影响字段和沿用数量。数值相同但证据变化的项目也需要核对。仅补独立观测时，可沿用全部水力输入，再更新算后对比。父版确认无法核验时，页面会请你完整复核。确认本版后再运行求解器。

安装和同机发版验收见[入门指南](GETTING_STARTED_CN.md)及[本机发版说明](LOCAL_RELEASE_CN.md)。
