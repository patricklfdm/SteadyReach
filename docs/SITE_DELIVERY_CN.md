# 开工时确定交付用途

[English](SITE_DELIVERY_EN.md) · [工程判断与恢复](ENGINEERING_DECISIONS_CN.md)

首页选择地点类型，展开**资料要求与交付条件**，点**采用这些交付条件**，在**用途和过流路径**选择本次用途。新项目与可编辑修订版均可采用模板，也可选择自定义。开算前在参数核对页查看随本版冻结的条件。合同有误差或余高要求时，记录限值与依据。

| 用途 | 两桥间纯河道 | 单处涵洞 |
| --- | --- | --- |
| 条件性初筛 | 两端分别在上游桥下游侧、下游桥上游侧。确认河段、流向、流量、适用边界、地形基准、河床假设和糙率，说明桥梁壅水是否影响结果。 | 逐组确认孔数、净尺寸、涵长、两端涵底、堵塞、道路控制高程、尾水、流量和糙率。在涵前及尾水结果旁列明假设。 |
| 方案比较 | 沿用相同河段、事件及基准，在可匹配断面对照基准版和修订版，解释水位、湿端和漫滩流量变化。 | 沿用可比的事件、基准和涵址，说明改变的洞口、堵塞或水力控制，对照涵前水位、道路越流及涵孔流量。 |
| 提交工程复核 | 提供关联原件的水下断面、已约定容差的独立内点水位，每个所选工况提供控制边界的单因素敏感性试算，复核影响范围。 | 提供逐组尺寸、涵长、同基准两端涵底及道路控制线测量原件，核查每个所选工况的原生道路越流量。合同有余高要求时填写数值与依据。另查入口、堵塞和旁路。 |

三种用途均核对断面湿端，发现湿端先核查连通和覆盖。方案比较还需可比的计算版本，正式复核需确认单主过流路径适用。湿端、超限实测偏差与缺少的必要原件均列为待办。现场过流和图纸解释由项目工程师复核。

仅改变用途时，可在可编辑版沿用现有地形、几何及水文资料，核对新增条件后再确认运算。原版保留原约定。条件未齐时可将该版交给工程师诊断。

在结果优先事项中可直接定位补测、断面或两版对照。先解决结果归属、原生输出缺失等问题，再解释水力现象。报告和离线交接页带有本版用途及首要工程判断。最小包提供可移交的原生模型，完整包附报告、证据和可用 GIS 成果。承诺地图交付前核对包清单。建筑受淹、桥梁自身水力表现和最终设计另需专项依据及工程复核。
