# 资料关联、集中准备与一次最终确认

[English](AUTOMATION_EN.md) | **简体中文** | [无已有模型指南](NO_MODEL_GUIDE_CN.md)

使用模型页面的 **集中准备，运算前统一确认**。它减少重复转录和逐项操作，同时保留必要的工程判断，不把未知埋藏结构当成实测数据。全部在本机运行，不需要 AI 服务；最终确认之前不会启动 HEC-RAS。

## 新建模型的快捷路径

1. 创建地点，等待 USGS 地形与资料查询结束，导入已有的本站资料文件夹或文件。核对过路位置、流向、高程单位和基准。根据材料在地图指认各组进出口，或关联含义明确的测点。
2. 在 **集中准备，运算前统一确认** 点击 **自动准备草稿（含标注的估计值）**。后台复用已提取文本，解析支持的资料，生成或修正适用的 DEM 几何，提出岸站并填入一致的来源值及带标注的条件性估计。初始布置会写入可编辑草稿，结束后检查地图与不确定标记。
3. 处理集中显示的来源差异及剩余缺项。已有手动值优先保留。岸站剖面支持网格和左右岸站距数字输入，数字会对齐最近 DEM 样点，并显示实际站距及待保存提示。单断面编辑和剖面总览均可通过 **保存全部更改** 或 **核对全部参数** 统一保存。切换断面时保留待保存选择，越界或左右顺序错误会持续提示并阻止保存。
4. 打开 **核对全部参数**。系统先按当前依赖刷新自动填写的值，再绑定核对清单。确认页集中显示不确定岸站和资料提取限制，可直接定位相关参数。检查这些判断及完整数值、假设、道路方向、底板／入口／淤堵、过流路径与边界，一次确认后运行 HEC-RAS 并生成报告及两个交付包。

自动准备按钮允许生成可编辑的条件性草稿，最终计算勾选框授权运行求解器。候选缺失或相互冲突时继续等待处理。已填自动估计失去依据后会清空并列为缺项。用户手动修改某项后，该项由用户控制，后续自动准备会保留它。

### 草稿支持的条件性估计

- 已辨认的洞口坐标可推导平面涵长、接近段距离和孔位。同组多孔等距布置需要明确的墙厚／孔间距。
- 外侧 DEM 短剖面通过采样及拟合稳定性检查后，可提出条件性涵底。参考范围表示不同拟合窗口的外推结果。需核对河床／底板连续性、淤积和跌坎。
- 已有路宽及兼容洞口／断面时，程序在限定范围搜索道路候选。进出口分别采样，保留外部 DEM 高程，并在合适路肩间连接涵孔包络。整个路顶剖面标为假设，保留采样与搜索边界，需核对方向、覆土及绕流。
- 箱涵可准备标为假设的混凝土底板及直角端墙情景。混合流、混凝土糙率、损失系数和零填塞均可修改，来源冲突保留待选择。
- 端部断面岸线不明确时，在已有搜索范围内尝试扩宽 DEM 采样。适用时可由相邻两条断面的岸线连续性外推，保留低置信度假设标记。缺高程、相交和仍无法辨认的岸线继续列为复核事项。

道路、结构估计及断面几何需要核对现场适用性。水力警告、敏感性和工程接受分别保留复核状态。

## 详细资料与几何工具

1. **查询／导入本站资料。** 先运行已有的 USGS DEM、资料目录查询及附件解析。查看资料数量、测量坐标系、高程单位／基准和失败记录。公开下载不可用时导入本站资料文件夹。自动获取限于已支持的资料源和格式。
2. **自动提出并核对外部流路。** 使用 [DEM 自动布置](DEM_AUTOMATION_CN.md)生成锚点、位置／宽度和岸站候选，无需先逐点布置。优先使用已存来源关联；仅坐标时可能出现不同流向的方案，先确认实际流向与道路间隔，再采用。已有断面使用 QA 建议；有歧义时才手动选点。
3. **集中关联涵孔。** 展开 **多组涵孔与测点关联**，点击 **自动建议全部洞口配对**。当只有一份适用测量且进出口点群可区分时，程序从 `LC`、`CROWN` 代码提出矩形主孔与圆管配对，按面向下游的横向顺序排列，不写死点号。对照草图／地图核对进出口编号、组号和组内孔号。配对有歧义时保留未解决；其他代码可直接填写测点编号关联。
4. **选择高程代表什么。** “仅位置”不推导涵底；“已辨认的内涵底测点”按原单位换算高程；“假定内顶／低梁底”以测点平均高程减去已填净高，结果明确标为 **假设值**。外顶、外径、淤积、不同位置的梁底变化都可能使此假设失效。不自动转换高程基准。同一洞口多个编号会取平均，不能混合不同涵孔或无关表面。
5. **保存关联。** 生成候选，不覆盖已采用的尺寸和涵底。只有勾选允许创建新组时才增加显示的新组，未知尺寸仍留空。同组多孔要关联每一孔；不同涵长／涵底不会被悄悄平均，应分组或明确采用兼容的结构表达。
6. **生成断面，先解决几何问题，再复核岸站。** 提前检查断面相交、缺失高程、涵孔投影重叠／超界、涵底反坡以及已填写的接近段长度约束。尚未采用孔位时也可看到配对提案的预警；确认关联后的冲突会阻止相关孔位采用及最终求解。点击 **查看断面**，获取有限角度的方向建议，再用真实 DEM 重采样预览。检查过流方向和覆盖后才采用；方向建议不代表水力验证通过。
7. **集中核对候选和剖面。** 在 **集中核对参数候选** 中，已有值默认“保留已保存值”。**选中缺项的唯一候选** 只是准备选择，查看公式／条件后再点 **保存全部所选更改**；冲突候选保留待选择。可直接跳到完整表单修改任意值。**岸站剖面总览／集中选择** 显示已存岸站和不确定性，展开需要看的剖面、修改并勾选后一次保存，不会把全部已存岸站替换成算法默认值。
8. **最后只确认一次完整模型。** 打开 **核对全部参数**；缺失或无效项仍等待修正。核对估计值、底板／入口／淤堵、边界、过流路径及完整数值后，只有 **确认并运行 HEC-RAS** 才启动求解。资料或几何改变会使旧确认失效，过期推导值须重新采用或明确修改。

## 自动推导内容

| 候选 | 计算与限制 |
|---|---|
| 涵长 | 在测量原始投影坐标中计算关联进出口中心的平面距离，再换算国际英尺；不是涵身水力长度的实测值 |
| 涵底 | 已辨认的内部涵底测点，或明确假定的“内顶减净高”；必须高程基准一致 |
| 每孔进出口横距 | 正交投影到各自外侧断面的站距轴；斜交可能压缩孔间距，因此采用前检查重叠 |
| 进口至上游断面距离 | 进口至断面线的垂距，作为条件性接近段长度，不一定等于沿涵轴的距离 |
| 无测量时的多组涵孔 | 在地图选择 **进出口点选所属涵孔组**，分别点选各组洞口，得到各组涵长、距离及横距候选。同组多孔等距布置还需已填写孔间净距；仅凭 XY 点位不推导埋藏涵底 |
| 路顶 | `RDCL`／`CREST` 测点高程及投影横距；需确认它们确实代表越流高点且覆盖足够，路中线未必是堰顶。仍可绘制路顶线并从 DEM 采样 |
| 主槽流程长度 | 同一外部河段内，沿已保存流线计算两断面之间的距离；左右滩地暂用明确的等长假设。跨越覆盖结构的区间仍使用单独的条件性直线距离候选 |
| 糙率、损失和正常水深坡度 | 现有带依据的文献选项与适用的外部地形推导，保留适用条件；不自动校准 |

## 进度保存与修改规则

- 不改变原始资料及 DEM。操作显示处理中、已保存或可处理的错误。
- 重新打开断面工具时恢复仍有效的未采用预览；手动预览工具等待“采用”；自动准备按钮会将适用的布置写入草稿，等待最终核对。输入版本、关联或来源变化后须重新预览。
- 重采样仅清除变化剖面的岸站选择；其余已存岸站和仍有效的复核标记保留。平移断面中心会使相邻流程长度失效；改变上游结构面会使依赖它的孔位、道路站距和距离失效。保持中心的旋转不会丢弃未变化的中心间流程长度。
- 已采用的推导值保存公式、测点关联、文件哈希、单位和假设。依据变化时标记过期，最终求解前会拦截。
- 这些记录是计算上下文，不是签名或工程认证。不新增审核人、填写理由或上传证据的行政步骤。

资料含义、构造、局部淤堵、有效过流路径、边界适用性及模糊岸站仍可能需要人工判断。不能为了填满表单提供无依据的数值范围。空间检查、水力求解完成和工程结论合格仍是不同状态。

## 集中保存，再进入结果复核

**保存全部更改** 会提交表单编辑、已选参数候选、洞口关联和岸站批次；常驻提示列出未保存项目。返回项目列表、切换语言或打开最终参数核对前也先保存所选更改。保存按顺序执行：后面的批次过期时，前面已成功的保存保留，未成功选择继续等待修正。保存地图点位后会刷新关联候选，并保留待保存选择。依据变化的旧选择会标为过期，等待更换或清除。单项候选按钮同样检查当前来源和关联依据。**选中已变化的推导值** 只准备更新候选，不替换手动值。浏览器刷新／关闭可能丢失未保存候选或岸站选择，应先等“已保存到本机”。

计算完成后使用[结果补充、独立修订、湿端点筛查和敏感性批次](RESULTS_REVIEW_CN.md)，减少重复转录和导出，同时保留工程判断。
