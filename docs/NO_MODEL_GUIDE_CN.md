# 没有现成 HEC-RAS 模型时如何开始

[English](NO_MODEL_GUIDE_EN.md) | **简体中文** | [首页](../README.zh-CN.md)

本指南用于 SteadyReach，启动入口为 `start_workflow.cmd`。只处理一个河段、一个箱涵／圆管交叉口的 1D 恒定流；多个不同涵孔可分组。日常操作在浏览器完成，不要求 AI、审核人姓名、签字、逐项理由或截图上传。

## 先准备能找到的资料

| 必要信息 | 优先资料 | 缺少时怎么处理 |
|---|---|---|
| 经度、纬度、实际过路位置和流向 | 定位点、航片、现场照片 | 经纬度用于自动获取 USGS DEM；河道及涵洞点位需要在地图上辨认 |
| 设计流量及工况 | StreamStats 或适用的水文报告 | 不从地形猜 Q100；等待填写，单位 cfs |
| 孔数、形状、净宽／直径、净高 | 图纸、测量、有尺度照片 | 输入明确的资料值或假设；不同尺寸、涵底不能强行归成相同孔组 |
| 涵长、各组进出口涵底及高程基准 | 实测、竣工图 | 点选进出口可提供顺直涵长候选；满足条件时提供外部河床外推涵底假设，均需主动采用 |
| 底板、入口构造、淤堵 | 图纸、入口近照、检查资料 | 明确填写或选择条件性假设；空白不等于“无淤堵” |
| 道路有效宽度和路面高点剖面 | 路面测量、图纸、DEM | 可沿点选高点线采样；道路宽度仍需明确填写，不能用它冒充涵长 |
| 河槽／漫滩／涵洞糙率、入口和出口损失 | 现场状况及技术参考 | 页面给出有适用条件的文献候选；不适用时直接改值 |
| 断面、左右岸、流程长度、边界 | DEM 和现场／测量资料 | 自动采样与候选计算；用户检查过流范围、流向和代表性 |
| 平面坐标系、高程基准、单位 | DEM 元数据和测量说明 | 自动读取可用 DEM 元数据；不自动消除测量基准差异 |

先使用 **查找、导入与核查资料**：公开查询、PDF／文本提取、测量 CSV 及本机 Windows OCR 会提出可核查候选，保留已有输入。测点可直接叠加 DEM 查看，不要求另去 QGIS 操作。详见[资料辅助指南](SOURCE_ASSIST_CN.md)，包括覆盖范围、文件夹导入、单位和失败处理。

## 1. 建项并自动准备地形

双击启动器，选择“坐标／部分资料”，填写名称与 WGS84 十进制度坐标。美国西经为负数。已知的流量和糙率可先填，其他项目留空。点“准备项目”，等待地形和元数据准备完成。

页面会显示正在处理、完成或失败；失败时草稿仍保留，可重试。必要资料不全只会停在补齐页面，不会开始求解。

## 2. 填写已知参数

在“A · 流量与糙率”和“C · 涵洞与道路”填写资料中已有的数值。每个数值旁显示来源类别；展开“来源／修改数据类别”，可选择“从资料中转录”“用户填写／修改”或“估计／假设”。该选择不要求姓名或理由。

没有把握时可以保持空白，也可以明确填入假设。程序提供的候选会保留“假设值／估计值”等标签，修改候选数值也保留先前来源记录。用户转录值不等于程序已经独立核实。

## 3. 点选外部河段，生成断面

1. 在“B · DEM、断面和左右岸”检查高程单位及基准，点“载入／刷新 DEM”。可放大、缩小。
2. 点“点选上游河段”，按水流方向，从远端到涵洞前点至少两点。
3. 点“点选下游河段”，仍按水流方向，从涵洞后到远端点至少两点。不要让外部河段穿过覆盖涵洞的道路。
4. 断面宽度／间距的 200／40 ft 仅是可改的采样建议。保证两侧河段足以形成至少四条功能断面，并覆盖可能过水范围。点“生成／替换候选断面”。旧草稿保留在历史记录中。
5. 查看剖面和不确定提示。左右岸按钮有选中颜色，再点一次可取消；点剖面采样点修改。也可采用全部已显示候选，或在“全部断面数据”直接改值。
6. 查看“布置候选”表，再批量采用缺失项。它包含模型名称、结构／外侧断面河站号、岸站和流程长度候选；不覆盖已有值。

点位自动保存，按钮模式和点数会显示。撤销作用于当前选中类型的最后一个点。修改点位不会自动重写已生成断面，需明确点“生成／替换”。替换会重新生成岸站和结构位置候选。

流程长度初始候选采用断面中心直线距离，并明确假设左滩／主槽／右滩相同；弯曲、分流或不等长漫滩需要修改。河站号是模型标识，不是测量里程。断面相交、缺测、岸序错误等仍会阻止运行。手动修改采样高程或位置后，原 DEM 记录保留，修改值不会继续冒充未经修改的 DEM 样本。

## 4. 按需利用结构和道路候选

- **涵长和布置：**在 DEM 地图上点选进口、出口的涵孔组中心。对于单一相同孔组，程序可根据两个点给出顺直涵长和进口距离候选。输入孔间墙厚／净间距后，还可生成等距平行孔的横向中心位置。斜交、弯曲或多组不等孔应逐项填写。
- **涵底：**已采用外侧功能断面和岸站、已点选洞口，并有附近外部 DEM 断面时，程序可以将岸站内河床低点短距离外推到洞口，提出“河床与涵底连续”的条件性假设。它不是地表 DEM 对埋藏涵底的实测。淤积、跌坎、植被或路堤会使假设失效。显示的区间只是近端河床与外推河床之间，**不是真实涵底误差上下界**。不满足条件时不提供数值。
- **路面高点：**先采用进出口外侧断面河站号；再面向下游，从左到右点选道路高点线，点“采样已点选的路面高点线”。剖面候选出现在“涵洞与道路”，需明确采用。检查 DEM 是否覆盖真正高点以及是否遗漏低侧绕流。
- **系数：**每个文献候选都显示适用构造或河道条件及官方链接。文献区间不是本站实测误差。断面损失可批量选择明确显示的渐变／突变方案；混合流、急流不能机械沿用缓流经验值。
- **边界：**“单位与边界”可显示外部河段正坡降候选，近似正常水深能坡。坡降范围是所采相邻段的差异，不是统计置信区间。负坡、数据不足时保持空白。检查边界距离与敏感性，不用涵底坡度代替远端能坡。

所有模型输入仍可修改。数组支持逗号分隔；二维数据每行一组，或粘贴 JSON 数组。修改后等待“已自动保存到本机”。

## 5. 集中确认，然后真正运行

点“核对全部参数”。这里列出全部模型参数、单位、来源类别，以及工程设置与来源文件。长采样数组可以展开查看；“修改数值（全部字段）”允许直接编辑任何表单参数。

若缺项或检查未通过，会显示对应项目并提供定位按钮，运行保持禁用。修改后点“保存并刷新参数清单”。

确认内容正确后，勾选“我已核对这些输入、估计值、左右岸及限制”，再点“确认并运行 HEC-RAS”。这是唯一必需的集中确认，不是工程设计签署。未确认不能调用实际求解；确认后参数或文件变动会使旧确认失效。

此后自动建立原生模型、运行求解器、提取结果、生成中英文 DOCX／PDF 及英文摘要，并按选项生成 Mapper、QGIS 展示图和两套交付包。关闭 GIS 时输出原生模型包，不宣称有地图。保留启动窗口。

## 6. 取结果或结束

结果页可打开最小包和完整包。完整包会保留最后参数清单、确认记录、已上传资料和相关估算记录，方便检查假设。水力警告独立显示，`READY_FOR_REVIEW` 不等于设计合格。

不想继续时，展开“停止此项目”，点“放弃工作流”，再点页面内“确认放弃”。已保存文件保留，无需解释原因。

普通新地点仍需要工程师识别流向、结构构造、输入适用性与计算警告；该版本不自动认证工程结论。
