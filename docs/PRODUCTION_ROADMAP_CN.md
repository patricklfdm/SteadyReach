# 一维恒定流的生产化开发顺序

[English](PRODUCTION_ROADMAP_EN.md)

首个生产场景设在本地 Windows 工作站。工程师建立单河段初筛模型，比较恒定流方案，把可追溯的 HEC-RAS 工程、GIS 和报告交给同事。以下验收标准围绕这条链路。其他水力模型和跨机器验收另行安排。

| 优先级 | 开发内容 | 闭合条件 |
|---|---|---|
| 1. 明确工程决策 | 与复核工程师约定用途、事件、河段范围、可接受误差和采用结论所需的证据，将结论写入两版报告。对需模拟桥梁、分流、洪峰传播的项目在入口提示调整建模方法。 | 验证前冻结准则。用一个适用项目和一个需调整分析方法的项目验收。观测对比未达标时，报告封面保留该结论。 |
| 2. 验证现场表现 | 在 Siletz、Big River 现有对比之上，增加独立地点和事件，收集同期流量、水位、测量误差和基准，涵盖低流量与洪水。率定前划出独立验证观测。 | 按事件给出偏差、最大残差及位置、可用独立点数和观测误差。已用作边界的水位剔出精度统计。工程师针对本站用途给出采用意见。 |
| 3. 让缺资料时的下一步明确 | 自动检查资料年代、覆盖、事件同期性、评级曲线适用范围、水尺零点变化和水下测量。缓存原始响应和旧版本，指出哪份缺失资料最影响判断、可向谁索取以及会影响哪项计算。 | 冻结项目可离线复现；接口失败与查无记录可区分；附近水尺缺少边界水位传递依据时，报告显示条件性。工程师提供或审核传递关系，必要时安排测量。 |
| 4. 按水力影响处理警告 | 将原生警告与断面剖面、漫滩流量、边界影响和实测残差关联。按照对工程决策的影响排序，保留基线、修订依据和放弃的方案。 | 重放 Merced 漫滩和 Pagosa 边界案例。列出受影响站号、最大水位差、湿端及新警告。某方案虽减少警告却恶化观测吻合度或过流路径时，系统能指出。 |
| 5. 保护交付并可恢复 | 在现有任务记录、指纹、备份及单份 PDF 恢复之上，加入老项目升级与回退演练、可发送的诊断包、附件外发检查、依赖清单和发行包校验。 | 在同机中断任务、模拟公开服务不可用、导入旧项目，能恢复产物并核对运行编号。演示一次客户脱敏交付和一次可验证的回退。 |
| 6. 量化新工程师使用体验 | 分别观察从坐标、部分资料和完整测量包起步的操作。记录首次双包成功率、人工时间、机器时间、等资料时间、开发者介入及停在哪一步。 | 试点前约定目标，按入口公布样本数和分母。由工程师独立做完一个真实项目，再由同事打开交付包，分别收集反馈。 |

建议从 Jeff 复核冻结的 Siletz 案例开始做前两项。2018 年 1 月的内点水位残差为 +0.524 m，超过该案例预设的 0.15 m 调查阈值；同输入重算能复现全部 18 条断面的水位和流量。Soquel 适合验证异地测站水位传递，Big River 适合验证观测偏差较小但测量精度缺失时的处理。每个地点承担不同的验证任务。

USACE 的恒定流教程通过观测水位、下游边界和糙率敏感性复核模型。FEMA 的通用水力指南也关注模型、纵剖面、地图、流量和洪痕之间是否一致。软件发布完整性和恢复机制可参考 NIST SSDF。具体报审项目还需另行核对当地要求。[USACE 恒定流教程](https://www.hec.usace.army.mil/confluence/rasdocs/hgt/latest/tutorials/1d-steady-flow/steady-flow-modeling-with-hec-ras) · [FEMA 通用水力指南](https://www.fema.gov/sites/default/files/documents/fema_guidance_general_hydraulics_considerations_nov_2024.pdf) · [NIST SSDF](https://csrc.nist.gov/pubs/sp/800/218/final)
