# SteadyReach 逐步使用说明

[English](USER_GUIDE_EN.md) | **简体中文** | [首页](../README.zh-CN.md)

## 1. 打开程序

双击 `start_workflow.cmd`，保留启动窗口。程序打开本机浏览器页面，所有项目文件留在本机。环境已安装时，日常使用无需输入 PowerShell 命令。默认英文，右上角点“简体中文”。

如果没有 Python 环境，启动器会调用保留的安装程序。HEC-RAS 必须安装并能被发现；QGIS 用于可编辑 GIS／出图，LibreOffice 用于 PDF。若已有工程占用求解器，请自行保存并关闭该工程；程序不会替你关闭无关工程。

重启启动器后，在首页“已保存的项目”中选择“打开／继续”。每次本机服务地址可能改变，应使用本次打开的页面，不要使用旧地址书签。

## 2. 选择起点

**坐标／部分资料：**填写项目名称、WGS84 十进制度经纬度。美国西经填写负数。已知流量才填 cfs，也可填写已知主槽和漫滩 Manning n。未知项留空，点“准备项目”。程序查询并下载 USGS DEM、读取可用元数据，然后停在需要补充的模型参数页面。

**已有模型：**一次选择 `.prj`、目标 `.pNN`、对应 `.gNN` 和 `.fNN`；文件选择不可用时，可填写本机 `.prj` 路径。如果原工程保存的计划不是本次目标，明确填写如 `p01`。预览同时显示原保存计划和本次选择计划。无需提供旧结果文件，程序也不会导入它们。自动下载地图需要坐标；不要 GIS 时可以不填坐标，并取消 GIS 选项。

没有原生模型时，优先按[无模型详细指南](NO_MODEL_GUIDE_CN.md)操作：资料准备、地图点选、估计范围、路面采样及集中确认均有说明。

## 3. 在一个页面补齐模型

已有原生模型时，检查工况、涵孔组、断面、糙率和边界。填写模型英尺定义和高程基准；需要 GIS 时，再填写原生模型投影 CRS，并确认页面显示的 DEM 高程单位和基准。程序可读取 DEM 元数据候选，但不能可靠猜出没有记载的模型 CRS。模型与 DEM 高程基准不匹配时不会偷偷做高程转换。

先前填写的流量或糙率与原生模型冲突时，页面会明确提示。可以换成正确模型，或明确选择“改用原生模型参数”。原先填写内容另行保留，不会被静默覆盖。

没有原生模型时，展开“流量与糙率”“涵洞与道路”“单位与边界”“全部断面数据”等区域，按图纸、测量或工程判断填写。真正必要的技术输入仍包括流量、糙率、涵形／数量／孔径、涵长、进出口涵底、底板和入口类型、道路几何、边界和断面。无需填写人员姓名、理由或逐项确认。手填值记为未经独立验证的用户输入；点击“采用此候选值”会保留假设类别、范围和来源，不会伪装为实测。

需要 DEM 断面时，展开“DEM、断面和左右岸”，确认 DEM 单位／高程基准，载入地图，在涵洞上游和下游外部河段各点至少两个锚点，各段均按流向排序，避开道路覆盖的涵洞内部。断面宽度和间距只是可修改的采样建议，不是已知现场尺寸。生成候选后检查断面和左右岸位置，可以单条或集中采用。左右岸选择按钮会变色，并可再点取消。缺测地形、相交断面、错误岸序和已经过时的断面复核记录仍会阻止使用。涵洞结构和水文资料仍要补充。

“补充资料”支持一次保存多份附件，不要求附加说明或审核人。照片和 PDF 作为材料保留，本版不会自动把任意照片识别成水力模型。涵长、涵底等缺项在明确填写之前继续为空。

停顿片刻后自动保存，看到“已自动保存到本机”再离开；也可以点“保存草稿”。无效数值必须修正。回到项目列表或开始运行前也会保存。保存未完成时离开页面会提醒。重试下载会保留已填写草稿。

## 4. 集中确认后运行

点“核对全部参数”，检查完整清单、单位、来源及估计/假设标签。长数组可以展开，“修改数值（全部字段）”可直接修改。缺项或无效参数会列出并提供定位入口，运行按钮保持禁用。

修改后点“保存并刷新参数清单”，勾选一次确认，再点“确认并运行 HEC-RAS”。后端会核对输入文件和参数摘要；修改后必须重新确认，不能复用旧确认。不要求审核人、理由或逐项签字。

之后程序自动建立独立工作模型、调用真实 HEC-RAS、提取本次结果、检查结果身份和水力诊断、生成报告与两套交付包。选择 GIS 时，还会准备地形、等高线、可获取的离线航片、原生 Mapper 关联、QGIS 布局和展示图。保留启动窗口；可以关闭浏览器标签页。一次只处理一个项目。

## 5. 看结果和交付

结果页显示流量、涵前／涵后水位、流速和路面流量等可提取字段。横杠表示缺少可用结果，不代表零。多个涵孔组可能缺少可独立验证的分组流速。展开分组警告查看未解决问题。

Report_EN／Report_CN 提供中英文 DOCX 和 PDF；Summary_EN 为英文摘要。“最小交付包”含原生 HEC-RAS／Mapper／展示图；“完整交付包”额外包含可编辑 QGIS、双语报告、输入快照和运行／QA 记录。应整包保留子目录。审核修改或重算请使用副本，保留封存包的可追溯性。

READY_FOR_REVIEW 表示交付文件已生成并检查，不表示水力 QA、现场适用性或设计合格已经通过。“重新生成报告／交付包”可以在不重复求解的情况下重试导出。使用结果作工程结论前，仍要阅读警告。

## 6. 问题与退出

- 缺参数：补充、导入完整原生模型，或展开“停止此项目”后放弃。放弃保留文件，无需姓名或理由。
- 下载失败：恢复网络后“重试准备”，已保存参数保留。
- 不支持的计划／几何：提供受支持的恒定流模型，适配器不会猜测未知原生语法。
- 求解器阻塞：展开“技术详情”，查看任务日志并解决安装或已有工程占用问题；不会生成假结果代替。
- GIS 不完整：已经算出的水力结果可能仍可查看，修复原因后重试交付；缺地图时不宣称完整交付。
- 已完成后要改方案：建立新项目。这一版暂不提供已完成工程的原地改设计编辑器。

## 结果解释

公开模型复现检查软件行为，不代表当前现场状态。坐标与地表 DEM 不能确定埋藏结构。用于设计前请阅读[适用范围与限制](LIMITATIONS_CN.md)。
