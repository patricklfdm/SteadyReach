# 适用范围与结果解释

[English](LIMITATIONS_EN.md) | **简体中文** | [首页](../README.zh-CN.md)

本工具支持 Windows 原生、单河段、单个箱涵／圆管交叉口的一维恒定流，包括支持的涵孔分组。不提供非恒定流、二维洪水、泥沙输移、结构设计或任意 HEC-RAS 工程的通用导入。

**仍需人工决定：**代表性设计流量、结构开口／底板／入口构造、估算适用性、单位／基准、真实流向、断面／岸站／道路覆盖和水力警告解释。自动估算是条件性选择；地表 DEM 不能确定埋藏涵底。仅凭坐标不能生成可接受的工程结论。

HEC-RAS 适配器固定为已检查的 7.0.1 二进制。QGIS 3.44.15 及固定版本 PDF／Python 依赖已在 Windows 运行过，其他系统、软件版本及机器需要各自检查。

以下状态必须分别看待：

| 状态 | 含义 |
|---|---|
| 计算完成 | 新的原生求解产生身份匹配的输出。 |
| 报告／交付包完成 | 文件生成且依赖检查通过。 |
| 水力 QA | 仍需检查警告、连续性、流态、边界及数值稳定性。 |
| 工程接受 | 负责工程师认可输入与结论适用于该场地及目的。 |

自动提取可能缺少完整原生警告表、道路／分组流量。缺测值保留缺测。道路余高为正不能证明所有绕流路径干燥，岸站余高不等于堤防防护高程。展示图表示地形和模型位置，不是验证过的洪泛范围。

USGS 示例可与公开模型结果比较，复现不等于现场率定。形成设计结论前应查看原生输出并检查关键输入敏感性；最终解释及接受由用户与负责工程师决定。

## 新增自动化的边界

原生表补充仍是用户导出后严格自动核对，不是自动操纵界面抓取。已检查的适配器针对英文／US Customary HEC-RAS 7.0.1。独立修订适用于工作流构建模型；湿端点搜索范围有限，保留结构接近段，不能证明漫滩连通或收敛。敏感性只测试明确范围，不提供通用范围、现场校准或设计认证。OCR 可能漏读误读，目录覆盖有限。英文模板不自动翻译任意用户说明；残留中文构造说明会提示语言复核。

## 自动 DEM／QA 提案

[自动布置与 QA 修正](DEM_AUTOMATION_CN.md)补充了锚点搜索、自适应位置／宽度和保留原采样点的湿端点延长。结果页“根据 QA 创建修订建议”只在独立修订版提出改动，集中采用后还需完整参数确认才能运行。方向、过流连通性、结构、边界及未解决警告仍需判断；不等于收敛或设计验收。
