# 从模型输入到工程判断

[English](ENGINEERING_DECISIONS_EN.md) · [入门指南](GETTING_STARTED_CN.md) · [安装与恢复](OPERATIONS_CN.md)

## 计算前

在模型准备页打开**待判断参数与补测清单**。先处理来源冲突，再展开各组查看相应字段。点**查看输入与依据**可定位到原参数、来源和候选值。有现场资料缺口时可导出该组待测项。单纯查看依据会保留候选的待选状态。保存所需数值后，在参数核对页明确确认本次计算。

补测回传版会逐项对照原版确认记录，清单列出受影响字段和沿用确认数。仅补充证据时，水力输入可能全部沿用。系统无法校验父版确认记录时，将打开完整核对页。

## 从首要问题到选版

在结果总览展开**从本问题跟进到选版**，点击**跟进此问题**，保存原运行与所查问题。可先索资或选择等待。收到资料后从同处核对回传表及原件，在独立修订版中检查受影响的输入，确认后才重算。修订版的准备页、确认页和报告保留原问题及运行编号。没有现场测量时，把试算值保留为假设。

在新结果中对照原问题、可比位置和仍存限制，明确选择采用本工作版、保留上一版或等待资料。选择工作版后，用已有计算刷新报告和交付包；选用基准版时从选版入口打开对应运行。两版存在未配对、移动或未核实位置时，只在列明的同中心断面引用差值。新增或移除的断面也列入覆盖缺口。混合流河段的工程复核须对上下游分别做覆盖该工况原生断面的单因素试算。结果页和断面图集列出受边界影响的位置，引用当地水位前应核对同期边界控制。

## 计算后

在结果总览阅读**下一项工程判断**。中英文技术报告和离线交接页使用同一份证据生成该项建议。补充观测或敏感性试算后，请刷新报告和交付包，交接前核对运行编号。

| 看到的结果 | 工程处理 |
| --- | --- |
| 原生警告减少，但同一独立测点的绝对偏差增大 | 保留参考版供该测点比较，核对高程基准、几何及边界控制后再选版。 |
| 加密达到数值阈值，实测水位仍超项目限值 | 核对事件时刻、高程联测和出口水位。优先补能区分偏差来源的水下断面或分股流量。 |
| 修订后显著流量转入漫滩，沿程水位也发生变化 | 沿相邻断面和开口核对洪水通道，必要时补测控制断面，再决定是否采用。 |
| 数值筛查表现良好，但测点的垂直精度没有记录 | 初筛仅适用于已登记的流量、位置和河段。取得测量精度后，再评价现场验证结果。 |

项目负责工程师确定用途与阈值。是否可用于设计须由工程师另行判定。

## 工时与故障处理

在**报告与地图**内打开试点计时面板，点**查看已记录的工作量**。已记录请求统计成功提交的操作。重复确认指相同确认凭据的再次提交。机器任务时间、求解时间、工程师计时和等待资料时间各自列出，时段可能重叠。缺少计时记录或历史确认标识的项目显示为未测量。

点**项目诊断**，或点报错旁的**查看诊断详情**。先预览故障类别、版本、软件指纹和登记的原生结果标识，需要交给支持人员时再下载 JSON。补测表与当前计算版本不匹配时，从本版重新下载，对照站距顺序和高程基准核查原件。QGIS 出图超时可到**报告与地图**，用已保存的水力结果重新生成交付包。交接前请核实两个包的清单和选定运行。

管理员可在 SteadyReach 环境运行 `python scripts/deployment.py support --control <控制目录> --token <迁移凭据>`，核验既有签名升级或回滚后的活动版本、项目清单和保留备份。实际切换与回滚命令见[运维指南](OPERATIONS_CN.md)。
