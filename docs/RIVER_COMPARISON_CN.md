## 在同一断面核查漫滩和边界影响

打开纯河道结果页中的「按断面查看漫滩和边界影响」，通过下拉框或点地图上的断面线选择 RS。所选几何版本决定航片上的线位及原生地面剖面。表中同时列出左右漫滩流量比例及水位超出断面两端的深度。「全河段」可查看更长的路径。道路与堤线按当前河段范围查询并在本地缓存。USACE 没有返回线位时，本地堤埂仍需核实。

下图显示**原模型几何**在各边界试算下的有符号水位差，可查看当前断面的响应及绝对差超过 0.10 ft 的断面数。如果没有可用工况，先做边界敏感性批次。道路中心线能帮助确定核查位置，堤顶高程、涵洞和低洼开口仍需独立资料。

用实测河道验证模型的实例见 [East Fork River 校准和独立检验](../examples/east_fork_wy/README.zh-CN.md)。

## 在结果页判断下一步

1. 在「已保存的项目」中打开已计算的河道版本，核对工况、流量与单位。加州洪峰频率候选的流量依据会列出 USGS 站号、工作簿单元格和该站距坐标的距离。
运算前核对遇到多个候选时，可点「集中选择缺项的资料候选」。先看数值旁的河名、站号或来源再采用。岸站置信度 LOW 表示需要进一步看剖面。

若公开查询或下载失败，准备页和最终确认页都会列出受影响的来源。提取统计只涵盖本地文件。可重试查询，或从本站文件夹导入相应的官方卷册，再回到候选清单核对河名、页码与数值。

2. 展开「并排比选两种几何修订」，输入断面总宽上限（ft），点「预览两种几何」。检查固定方向延伸、允许旋转这两种方案的断面改动、岸站位置及漫滩连通性。一次确认后点「统一运行两个修订工况」，保留原模型及两份求解结果。
3. 三张地图比例相同。选择 RS，核对两端高程、水位变化、左右漫滩分流及临界水深回退。红点表示新增湿端，绿点表示已消除，橙点表示仍过水。总数相同也可能涉及不同地点。原生结果缺值显示为空，可下载逐断面 CSV。
4. 检查边界影响时，在「从已保存输入建议试算范围」选择有依据的边界，预览高低端、确认计算。在结果里查最大水位变化、所在断面及超过筛查阈值的断面数。结论适用于本次实际试过的范围和单因素变化。

## 导入实测资料

进入「实测资料与洪水事件校核」，下载空白 CSV。一条观测填一行，按 UTF-8 保存。选文件或直接粘贴含表头的 CSV，点「核查并保存观测」。原始表及核查记录会关联到这次计算。

| 列 | 填法 |
|---|---|
| event、date | 洪水或测量事件名称、日期（YYYY-MM-DD）。独立验证选另一场洪水。 |
| role、kind | 用途填 calibration（校准）、holdout（独立验证）、boundary（边界输入）或 context（背景）。类型填 stage（水位高程）、gage_height（水尺读数）、bed（河床高程）或 boundary_stage（边界水位高程）。 |
| x、y、horizontal_crs | 测点东、北坐标或经、纬度，以及相应坐标系，例如 EPSG:4326。 |
| elevation、unit、vertical_datum | 原始读数、单位（ft、us_survey_ft 或 m）、高程基准。若已转换，请在 source 说明转换依据。 |
| gage_zero | 水尺读数须填同单位、同基准的水尺零点高程。 |
| flow、flow_unit | 对应洪水的流量，支持 cfs、m3/s。河床测点可以留空。 |
| vertical_uncertainty、horizontal_uncertainty_m | 前者与高程同单位，后者为米。资料未报告时留空。 |
| source | 资料出处、页码或测量编号，注明坐标及基准转换情况。 |

测点至断面的匹配容差为 5 m，包含所填水平位置不确定度，并检查是否靠近多个断面。河床测点按其横距与原生断面高程对照。水位观测需核对位置、基准、事件、流量；现场仍需判断洪峰时间、河床变化、恒定流近似及测点代表性。

资料齐全的事件会出现「预览事件」。核对流量和边界后确认运算。结果页保留当前资料表对应的各次事件。偏差为计算高程减实测高程（ft）。用于下游边界的水位不能用于同断面的独立验证。不同事件分别用于校准与验证，并结合测量不确定度解释偏差。超出研究范围或基准有差异时，页面会指出要补哪项资料。
