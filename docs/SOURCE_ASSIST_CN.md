# 查找和使用工程资料

[English](SOURCE_ASSIST_EN.md) | **简体中文** | [无已有模型指南](NO_MODEL_GUIDE_CN.md)

模型页面整合了公开资料查询、附件导入、参数候选和测点地图核查。不需要 AI 账户，也不用填写审核人。原件和提取记录保存在本机，并进入本次计算的来源记录。

## 通常如何操作

1. 用坐标创建项目，准备阶段会尝试获取 USGS 地形和公开资料。已有项目点击 **自动查找可用资料／重试公开查询并解析**。处理中显示阶段和文件计数，请保持启动窗口运行。
2. 展开 **公开查询范围与尝试记录**，区分匹配、超时、资料源覆盖范围之外以及下载失败。目录的空间范围可能覆盖全州，搜索结果不等于已确认本站。
3. 用 **保存并解析所选资料** 导入 PDF、照片或 CSV。已有完整调查资料时，在 **导入此文件夹并解析** 粘贴已解压的**本站文件夹**路径，自动读取子文件夹。仅为查看测点不再需要先去 QGIS 导入。原件不变，不导入原生模型，相同内容会去重。限制为每文件 15 MB、每文件夹 100 份／100 MB。
4. 查看资料数、候选数和测点数。在 **原件与提取文本** 对照识别内容与原件。单份提取失败不会删除原件或阻止其他资料处理。手写／OCR 数值保留未核实估计标记，不标成实测结果。
5. 用 **查找参数／缺失项** 筛选必要缺失、来源冲突、有候选或全部参数。点击字段会自动展开对应组。每项“来源”详情显示获取路径、实际尝试记录以及下一步需要的资料。
6. 采用合适候选，或直接修改现值。查询不会覆盖已有输入。仅支持资料表中，距坐标 25 米以内唯一匹配且无不同流量候选的 Q100，可自动填入空白流量；它仍是待最终核对的资料报告区域回归估计。其他尺寸、假设和文本匹配须明确选择。数值不同会显示冲突，不自动替你决定。
7. 核查地图、断面和剩余工程输入，再打开 **核对全部参数**。缺失项、估计／假设和完整编辑清单分组折叠。展开相关组检查后，只做一次最终确认才启动 HEC-RAS。改变资料解释或文件会使旧确认失效。

## 已实现的自动获取路径及边界

| 信息 | 已实现路径 | 仍需判断 |
|---|---|---|
| 美国地形与元数据 | 原有 USGS DEM 查询、下载、坐标系及高程元数据候选 | 范围、基准解释和地形适用性 |
| 公开站点资料 | 有限范围的 ScienceBase 查询；USGS Massachusetts 30 处过水设施表按坐标匹配（发布 DOI：10.5066/P14HJGZI） | 是否为相同设施和工况；不是全国任意资料的自动参数解析器 |
| 测量资料下载 | 官方地址支持公开分段访问时，仅提取匹配站点的 ZIP 成员 | 使用公开目录下载表单，不使用需登录的 File Manager 地址；遇到验证码暂停自动下载，仍可导入本机资料 |
| Q100 | 支持资料表的 PK1AEP；文本／PDF／OCR 中明确标注 Q100 及 cfs 或 m³/s 的数值 | 水文适用性；不从 DEM 推算设计流量 |
| 其他参数 | 所有当前字段支持明确 field/value CSV；文本中带标签的河床／漫滩糙率、涵长、路宽 | 地点、涵孔组与单位；任意自然语言不能可靠地直接变成完整模型 |
| 测量 XYZ | 自动识别 CSV 列名或由用户下拉匹配，并转换平面坐标叠加 DEM | 坐标系、单位、基准；CROWN、CH、ABUT 等代码还需识别特征含义 |
| 测量控制 | 两个匹配的 OPUS NAD83(2011)、Massachusetts Mainland、NAVD88 控制点，在 0.03 米一致性检查后提出 EPSG:6492／美制测量英尺候选 | 此识别器范围有限，其他测量仍须明确元数据 |
| 涵长／净宽／路宽 | 两个用户指认端点的平面距离，转换为国际英尺 | 特征身份、墙厚、斜交以及平面距离与水力长度的差异 |
| 涵底高程 | 用户指认的单个真实涵底测点，基准匹配后转换国际英尺；保留原有适用条件下的 DEM 估计 | 内部涵底身份；不会自动把管顶点转换为涵底 |
| 道路／断面／左右岸 | 明确道路／流向线、DEM 采样、几何 QA 和岸站候选 | 流向、越流高点、水下地形、不确定岸站 |
| 边界／糙率／损失 | 已有地形坡度候选、带依据的工程参考范围，以及明确 CSV／文本输入 | 水力适用性与敏感性；参考范围不是本站置信区间 |

这不是全网搜索。“无明确可用值”只表示已支持的路径未提取出无歧义的适用值，**不代表网上没有资料**。市政 PDF、图纸、其他格式的设施表及照片仍可能需要工程师解读。程序不自动改变认证或 Windows 安全设置。

## 在测点地图中确认几何

展开测量资料卡。有坐标候选时查看依据；否则选择 X／Y／Z／点号／代码列，填写资料明确注明的投影坐标系、高程单位和基准，再点 **采用此坐标／列名解释**。不能仅凭坐标“看起来合理”就猜 EPSG。

在 **B · DEM、断面和左右岸** 载入地图。测点标注点号，并显示代码、原始高程及基准。密集点请先放大。不启用河段点选模式时，点击测点，或聚焦测点按 Enter，会将点号加入测量资料卡的选择框；已启用河段／道路模式时，则将该点精确坐标用于地图锚点。

在测量资料卡的测点表中选择目标字段：高程选一个真实内部涵底点，尺寸选两个端点。点 **由已指认测点生成候选** 后，仍须与现值及资料表值比较，再决定采用。管顶减直径、仅入口淤积、全涵长均匀淤堵是不同的条件假设，不能混为一谈。

测量坐标系与模型／DEM 坐标系分别保存。平面坐标可转换以便显示，但不自动转换高程基准。涵底候选要求模型高程基准已明确且与测量一致。模型水力高程使用国际英尺，原始测量数值和单位仍可查看。

## 可选的结构化参数导入

在资料导入卡下载空白 **参数 CSV 模板**，它列出当前项目字段及要求单位。只填写有资料的值，不要为了填满表格编造缺项。

列为 `field,value,unit,datum,evidence_class,source`。单位严格使用模板中写法，包括 `Manning n`；无量纲文本／设置的单位留空。数组、矩阵用 JSON，并遵守 CSV 引号规则。高程／涵底行必须注明与当前模型一致的基准。条件假设标 `assumed`，其余按资料报告值处理，不认定为独立核实的测量。空值忽略，未知字段、非法数值和单位不匹配会显示错误。需要多组涵孔时先添加对应组，再下载新模板。

完成后仍通过同一资料卡导入。内容会成为候选，而不是直接覆盖草稿。这是可选入口；普通资料查询、直接修改、测点／地图选择同样可用。

## 失败时怎么办

- **网络超时：** 仍解析本机已存资料，可以稍后重试公开查询，不自动给缺项填默认值。
- **公开下载与 File Manager：** 打开 [USGS 公开资料页](https://www.sciencebase.gov/catalog/item/6a6266c11ba49bb7d9d0603a)，在 **Attached Files** 点击 **Field-Based Hydraulic Model Survey Data.zip**。此按钮使用公开下载表单；`/manager/item/.../file/...` 是另一套文件管理页面，不能称为无需登录的直接下载链接。使用公开路径无需申请 File Manager 管理账号。如果出现验证码，由你在浏览器中完成，再解压并导入本站文件夹。程序识别到验证页面就暂停该下载，不自动解答或绕过验证、不索取账号，也不悄悄下载整个档案。
- **OCR 不可用／无可读文字：** 打开保留的原件，补充必要解释。OCR 使用本机已安装语言，不自动安装语言包或放宽脚本策略。
- **CSV 列名不认识：** 用下拉框匹配。原始测点列不会被当成水力参数直接赋值。
- **资料值不同：** 比较资料日期、内外尺寸、涵孔组、单位和基准，明确选择或修改所采用数值。
- **关键数据仍缺失：** 保留空白，或在现场依据支持下选择明确的条件性估计。通过必要输入检查并最终确认前，求解器保持等待。
