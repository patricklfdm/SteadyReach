# 团队正式复核与客户交付

[English](TEAM_REVIEW_EN.md)

打开已有计算结果的版本，进入**结果 → 交付 → 正式团队复核与客户交付**。日常试算可以直接完成。正式记录绑定工程版本、求解运行号、原生 HDF 和计算摘要。

1. 建模人选择**提交本版**，说明拟用范围或需要解答的问题。提交前须有与本版匹配的计算和交付包。
2. 另一位经办人选择断面或关联参数，填写意见。**退回修订**会保存问题。离线协作时下载 HTML 表单，交给复核人独立打开填写。导入回传的 JSON 后，先看姓名、断面和意见，再点登记。版本错配或已有新一轮处理时需重新取得表单。
3. 建立独立修订版并计算。打开**本版对既有复核意见的影响**，逐项查看哪些被引用的输入指纹发生了变化，集中复核这些项。提交新版后，已退回的祖先版本会记录由此版替代。
4. 复核人记录所述用途下的结论。交付负责人预览客户和内部文件，确认后生成正式交付。只发送 **Client** 目录，内含按收件范围筛选的两个包、两种语言的完整报告、原生模型及适用地图。**Internal** 清单留在本机，与复核历史和项目原始完整包一起保存。水力限制以技术报告为准。
5. 如需撤回，登记操作和原因。本机历史会保留记录；已收到副本的收件人需另外通知。

经办人信息记录本地操作责任。独立工程签审和身份管理按所在单位制度执行。已发目录供只读使用，需要调整时另建修订版。
