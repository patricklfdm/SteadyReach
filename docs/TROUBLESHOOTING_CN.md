# 常见问题

[English](TROUBLESHOOTING_EN.md) | **简体中文** | [首页](../README.zh-CN.md)

| 现象 | 处理方式 |
|---|---|
| 浏览器关闭或旧地址打不开 | 重新双击 `start_workflow.cmd`，保持控制台运行，在首页打开已保存项目；本地端口／令牌可能变化。 |
| 缺少参数 | 补齐标出的字段，或明确采用适用候选。草稿保留，此时尚未开始计算。 |
| 改参数后确认失效 | 保存并刷新全参数清单，重新确认改变后的输入。 |
| `.prj` 指向缺失的方案 | 同时选择目标方案的四个文件，并明确选择实际提供的方案；内附示例选 p01，不要重命名不相干文件来凑齐引用。 |
| Windows 双击 JSON 时报安全限制 | JSON 是数据文件，不是程序；从 VS Code／记事本的“文件 → 打开”查看。应用保存的项目不依赖双击关联。 |
| QGIS DLL／环境加载错误 | 从厂家安装的快捷方式启动 QGIS。重新运行安装选根目录，再检查环境；不要从不匹配的终端直接启动内部二进制。 |
| 下载／证书失败 | 保留 `status/setup` 日志，检查网络、系统时间及组织信任证书后重试；保持证书校验开启。 |
| HEC-RAS 不可用／版本不支持 | 正常安装受支持的 7.0.1，程序会拒绝未经适配的可执行文件。 |
| HEC-RAS 正打开其他工程 | 先自行保存并关闭该工程，再重试，不丢弃无关工作。 |
| 缺少 CRS 或高程基准不一致 | 填写资料注明的投影／基准，或关闭 GIS；不要猜投影或静默平移高程。 |
| 报告完成但地图不完整 | 阅读地图错误，补齐地形／航片或修复 QGIS 后重新生成交付；水力计算完成不证明地图完成。 |
| 结果为横线 | 该值缺测或尚未提取，不是零；查看警告及原生软件输出。 |

排查时在本机保留任务日志、`status/doctor.json`、项目输入及 summary 文件。仅向有权接收的人提供必要资料，日志可能包含本机路径。停止草稿可选择“停止此项目 → 放弃工作流 → 确认放弃”，文件仍保留供自行备份。
