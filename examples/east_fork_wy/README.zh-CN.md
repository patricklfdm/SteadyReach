# 用 East Fork River 两场实测洪水检验恒定流模型

[English](README.md) · [结果页断面联动图](../../docs/RIVER_COMPARISON_CN.md)

怀俄明州 East Fork River 有四条按测桩编号的 USGS 断面，编号 0220、0301、0421、0516 对应距下游基点 0000 的沿河米数。研究段长 296 m，模型冻结了 1979-05-21 的横断面，每隔 1 m 有一处高程。水尺和河床共用 NGVD29，原表相对高程加 2150 m 即得相应高程。

| 输入 | 原始表及位置 |
|---|---|
| 实测断面 | 表 4–7，印刷页 21、25、29、33。读取各表 5 月 21 日一列，原书标注了沿用的干地测值。[USGS 1979 断面测量](https://pubs.usgs.gov/of/1980/1190/report.pdf) |
| 校准，1979-05-30 | 表 10（印刷页 33）为 14:10–14:12 四断面水位。表 11（印刷页 35）给出 14:16 在 0000 处的流量 16.3 m³/s。[USGS 1979 水文记录](https://pubs.usgs.gov/of/1980/1189/report.pdf) |
| 留出检验，1980-06-10 | 表 49 和 50（印刷页 100、110）。四断面于 11:59–12:09 观测，以左、右岸水尺平均作为断面水位。12:15 在 0000 处流量为 19.3 m³/s。[USGS 1980 水文记录](https://pubs.usgs.gov/of/1982/0359/report.pdf) |

首页的可选练习读取 [practice.json](practice.json)。其中收录 1979 年 5 月 30 日糙率 n 为 0.030、0.035、0.040 的三次计算，每次保留四条断面的水位及原生 HDF 的 SHA-256。差值以 0.030 为基准，水位单位为米，高程基准为 NGVD29。RS 220 提供下游水位边界。下文给出了 Windows 复算方法。

## 在 Windows 复现

按主手册安装 SteadyReach 和支持的 HEC-RAS，在仓库根目录运行下列命令。每次运行都创建独立目录。

```powershell
.\.venv\Scripts\python.exe examples\east_fork_wy\field_trial.py
```

第一步最后一行给出该次输出目录，使用其中的校准记录执行第二步。

```powershell
.\.venv\Scripts\python.exe examples\east_fork_wy\field_trial.py --calibration "projects/east_fork_wy_check/<第一步目录名>/calibration.json"
```

程序按预设的 7 个统一糙率（0.020–0.050、步长 0.005）分别调用真实 HEC-RAS，以三个非边界断面水位均方根误差最小为准。第二步复核第一步的文件哈希，锁定糙率和几何，仅采用次年洪水的流量及下游实测水位。打开 `residuals.csv` 可查看逐点偏差（计算减实测），各工况另有原生 `model/Model.prj`、执行记录及原生警告文本。RS 0220 作为实测下游边界，两场的统计均排除此断面。

| 指标 | 校准 | 留出检验 |
|---|---:|---:|
| 选定／锁定的 n | 0.035 | 0.035 |
| 计入误差的断面 | 3 | 3 |
| 均方根误差，m | 0.0228 | 0.0147 |
| 平均绝对误差，m | 0.0201 | 0.0145 |
| 平均有符号偏差，m | +0.0130 | +0.0037 |
| 最大绝对误差，m | 0.0350 | 0.0162 |

两次选定方案的断面两端均未过水，HEC-RAS 均在 RS 0301 报告分流。结果检验范围为这一段短河道、两次融雪洪水快照和已知下游水位。岸站为建模判断，三个流区采用相同的相邻断面间距作为流程长度；扩散／收缩系数 0.3／0.1、缓流和恒定流量均为假设。水尺距对应断面约数米，USGS 给出的河床高程典型精度约 0.02–0.03 m。水尺记录取整，弯道横比降和跨年河床变化都会影响比较。没有足够资料计算绝对平面定位误差，原生模型使用当地里程示意坐标。此例不能据以制作实测淹没图，也不能外推其他河段 Q100 的精度。
