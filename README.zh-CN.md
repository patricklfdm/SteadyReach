# SteadyReach

[English](README.md) | **简体中文**

基于 HEC-RAS 的 Windows 本地一维恒定流河道与涵洞分析工具。通过浏览器的 **项目 → 模型 → 结果** 三屏操作，无需 AI 服务。

新模型先导入已有资料并核对设施位置和地形元数据，再点击 **自动准备草稿（含标注的估计值）**，集中生成断面、岸站和参数。修改突出显示的问题，最后一次核对完整模型。岸站支持数字输入及剖面网格。[准备指南](docs/AUTOMATION_CN.md)。

## 从这里开始

1. 下载本仓库 ZIP 并解压到可写目录，或 clone 仓库。活动计算建议使用本地磁盘，避免 OneDrive／网络同步目录。
2. 安装 **HEC-RAS 7.0.1**；需要可编辑 GIS 和展示图时安装 **QGIS 3.44 LTR**。参阅[安装说明](docs/WINDOWS_SETUP_CN.md)，此适配器不能直接假定兼容更新的 HEC-RAS 版本。
3. 双击 **start_workflow.cmd**。首次运行会准备本地 Python 和依赖，按提示选择 QGIS 路径；保持启动窗口打开。
4. 先试用内附的 [Phelps Brook 公开示例](examples/phelps_brook/README.zh-CN.md)，自己的地点参阅[没有现成模型时的指南](docs/NO_MODEL_GUIDE_CN.md)。
5. 集中检查全部参数，修改数值或假设，明确确认后才启动真实求解。在结果页打开报告及 **Minimal／Complete** 交付目录。

## 主要功能

- 支持 DEM 拖动与细粒度缩放，以及多条断面方向调整 → 真实 DEM 重采样预览 → 明确采用；保留相交检查及旧草稿。
- QA 提案联合比较邻近断面的方向和湿端延伸，旋转后重新采样，集中展示岸站候选供确认，并保留搜索范围及未解决水力问题。
- 纯河段结果可生成两级嵌套 DEM 加密提案，一次确认后批量调用真实求解器，比较水位、警告和湿端变化。[结果与加密指南](docs/RESULTS_REVIEW_CN.md)。
- 纯河段湿端修订可在已确认的宽度和轮数限制内连续计算，按每轮真实水位延伸 DEM 端点，自动导出最终报告与双交付包。[修订批次指南](docs/RESULTS_REVIEW_CN.md#湿端自动修订批次)。
- 可直接从已计算的修订或加密工况继续。独立可编辑修订版带入该工况的实际几何和来源记录，联合准备 DEM／岸站改动，集中确认完整参数后再计算。[续作步骤](docs/RESULTS_REVIEW_CN.md#从已计算工况继续)。
- 为美国地点查询 USGS DEM，准备地形、采样断面并提供左右岸候选。
- 结合相邻断面对岸站共同排序，保留人工控制值，标记插值及不稳定选择；修订结果显示已核验的逐断面水位差与警告覆盖变化。
- 导入支持的已有恒定流模型，或利用填写参数与地形数据新建模型。
- 标注建议／估算值，没有依据的必填项留空；无模型数值字段可修改，运算前集中确认。
- 真实调用 HEC-RAS，核验输出身份、保留警告，生成中英 DOCX／PDF 技术报告和英文摘要。
- 自动导出受支持的全部工况／涵孔组明细和完整原生警告表；旧运行可不重算，一键补导出并更新交付包。见[适用范围及桌面要求](docs/RESULTS_REVIEW_CN.md)。
- 生成最小原生模型包和完整包；开启 GIS 且资料、软件可用时，包含 Mapper 地形／等高线、QGIS 布局和展示图。

计算范围为单河段：不含结构物的纯河道，或单个箱涵/圆管交叉口（可含多个涵孔组）。[纯河道指南](docs/RIVER_REACH_CN.md)介绍排除桥梁的范围、已知水位边界和敏感性。地表 DEM 不能确认水下河床或埋藏涵底；计算或打包成功不等于工程设计合格。

首页支持删除已保存项目，并可从 **回收站** 恢复。文件保留供关联修订版使用，仍占用磁盘空间。

## 数据保存在本机

工作项目、下载数据、本机软件和报告运行时生成，由 `.gitignore` 排除。需要时备份整个工作项目；不要强制将被忽略的用户附件、计算结果或机器配置提交到公开仓库。

## 资料辅助输入

模型页面可按坐标下载有效 FEMA FIS，集中选择河流／Q100 位置和带页码的糙率候选，并可查询支持的公开资料、解析测量 CSV、PDF 文本／扫描页、DOCX 段落／表格、KML／KMZ 地点标记及带标签文本、尝试本机 OCR、将测点叠加 DEM，并提出带来源的候选。保留已有参数，区分冲突与失败，采用折叠分组和缺失项导航。详见[资料辅助指南](docs/SOURCE_ASSIST_CN.md)。资料源覆盖有限，未支持或有歧义的现场信息仍需工程师判断。

## 结果与后续修改

已选候选、关联和岸站可集中保存。结果页支持独立修订重算、原生表补充核验、报告／双交付包更新、湿端点定位、可选敏感性批次及 QGIS 复核副本启动。见[结果操作指南](docs/RESULTS_REVIEW_CN.md)。局部过流路径、结构解释和工程验收仍需判断。

河道报告现包含原生输入回读及绑定本次基准的已完成敏感性测试。测试后点击一次 **更新报告及两种交付包** 即可。完整交付包保留可追溯的敏感性证据与航片获取记录。详见[河段分析指南](docs/RIVER_REACH_CN.md)。
